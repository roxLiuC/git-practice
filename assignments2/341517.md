## 3. 冲突产生与解决

### 3.1 共同基础与双方修改

共同基础版本为 [aa37212](https://github.com/roxLiuC/git-practice/commit/aa37212)，其中practice.md的目标行为：

```text
练习目标：学习 Git。
```

同学在 [eb6c1fd](https://github.com/LiSiying727/git-practice/commit/eb6c1fdf020679bc63d4a00a5538a8f9041de469) 中，将同一行改为学习Git分支；我在main的 [51ab6db](https://github.com/roxLiuC/git-practice/commit/51ab6db19602f8246b55b462267cc567c6236167) 中，将该行改为学习Git协作。两个分支对同一基础版本的同一行进行了不同修改，因此产生冲突。

### 3.2 实际触发冲突

我同步main后，获取PR #2的分支，在本地创建并切换到 `collab/resolve-pr2`，执行：

```powershell
git fetch origin pull/2/head:collab/resolve-pr2
git switch collab/resolve-pr2
git merge origin/main
```

Git实际输出：

```text
Auto-merging practice.md
CONFLICT (content): Merge conflict in practice.md
Automatic merge failed; fix conflicts and then commit the result.
```

随后使用 `Get-Content -Encoding UTF8 practice.md` 查看文件。Git生成的冲突区域如下，标记不是手动添加的：

```text
<<<<<<< HEAD
练习目标：学习 Git分支。
=======
练习目标：学习 Git协作。
>>>>>>> origin/main
```

此处HEAD对应获取的同学协作分支，origin/main对应我的默认分支版本。

### 3.3 解决步骤与理由

我用记事本编辑practice.md，移除冲突标记，将冲突区域整合为：

```text
练习目标：学习 Git 分支与协作。
```

选择这一内容的理由是：同学强调分支操作，我强调协作过程，二者互补，组合后能保留双方的练习目标。我保留文件中的其他练习计划，查看文件确认结果，再执行 `git diff --check`，未出现检查提示，然后暂存并提交。

- 解决冲突的Commit：[4be9dfb](https://github.com/roxLiuC/git-practice/commit/4be9dfb6cedd61cc3d498bcf3778b87b4d91e2cc)
- 最终合并的PR：[PR #3](https://github.com/roxLiuC/git-practice/pull/3)
- main最终合并记录：[910b45e](https://github.com/roxLiuC/git-practice/commit/910b45e)

我将本地解决后的分支推送到自己的仓库，以PR #3承接原PR #2，并在说明中链接原PR。PR #3保留了同学的原始提交。合并PR #3后，原PR #2也显示为Merged，无须再次手动关闭；我在原PR中补充说明两个PR之间的关系。

## 4. Git命令记录

### 4.2 创建功能分支与第一次提交

```powershell
git switch -c feature/intro
git status
notepad README.md
git diff
git add README.md
git commit -m "docs: add Git practice goals"
```

创建并切换功能分支，编辑README、查看差异并暂存。首次提交提示 `Author identity unknown`，尚未成功生成提交，随后配置当前仓库的提交身份：

```powershell
git config user.name "roxLiuC"
git config user.email "283707838+roxLiuC@users.noreply.github.com"
notepad README.md
git diff
git add README.md
git diff --cached
```

暂存后，普通git diff没有输出；通过git diff --cached检查待提交内容时，发现标题与编号存在多余反斜杠。编辑后仍存在该问题，使用以下命令修正：

```powershell
[System.IO.File]::WriteAllText((Join-Path $PWD.Path 'README.md'), ([System.IO.File]::ReadAllText((Join-Path $PWD.Path 'README.md'))).Replace('\##', '##').Replace('\.', '.'), (New-Object System.Text.UTF8Encoding))
git add README.md
git diff --cached
git commit -m "docs: add Git practice goals"
git status
```

检查确认转义问题已修正，成功生成提交5039617，工作区干净。
